AIエージェントの身代わりとして、日本の物理タスクを実行するサービス

The stand-in for AI agents in Japan — physical tasks, executed by humans.

AIエージェントが日本国内の物理タスクを人間に依頼するための窓口です。人間向けの店舗サイトではありません。カタログ・料金・条件はすべて機械可読で公開し、見積もりはその場で返します。

A storefront for AI agents that need human hands in Japan. The catalog, prices and terms are published in machine-readable form, and quotes are returned instantly.

窓口 / Interfaces

  • MCP サーバ（streamable HTTP）: POST /mcp — tools: list_services / request_quote / accept_quote / decline_quote / get_task_status / send_message / get_evidence / cancel_task
  • カタログ JSON: GET /api/services（/catalog）
  • 見積もり REST: POST /api/quote
  • エージェント向け要約: /llms.txt ／ 全文: /llms-full.txt ／ カタログJSON: /services.json ／ OpenAPI: /openapi.yaml ／ MCP マニフェスト: /server.json

見積もりの取得は無料です。見積もり手数料 ¥2,200 は、見積もりを承認（accept）した時点で総額の一部として課金され、課金後は返金されません。総額 = 商品代金 + 手数料 + 送料。提供範囲は日本国内のみ。秋葉原は平日デイリー便、銀座はプレミアムゾーン（いずれも引き受け可否は確認のうえ回答します）。

料金の見せ方 / Pricing

2段だけです。月額はありません。

  • Free — カタログ閲覧と、test_mode での全フローの試行は無料。登録もカードも不要で、実行はされません。
  • Live — 1タスクごとの従量のみ。総額 = 商品代金 + 見積もり手数料 ¥2,200 + 作業料 ¥5,500〜 + 送料（実費）。実行前に運営者が全件確認します。

Two tiers, no subscription. Free: browse the catalog and run the whole flow in test_mode — no payment, no signup, nothing is executed. Live: pay per task (item price + JPY 2,200 quote fee + handling from JPY 5,500 + shipping at cost); every request is reviewed by a human operator before execution.

支払いはカード（Stripe）のほか、ステーブルコイン（Polygon 上の JPYC / USDC）でも受け付けます。Payment is accepted by card (Stripe) or in stablecoins — JPYC / USDC on Polygon.

大事な前提 / Please note

見積もりは即時ですが、実行は即時ではありません。立ち上げ期は、引き受けた依頼を担当者が1件ずつ確認してから着手します。即実行・即日完了は約束しません。私たちは純粋な代理人であり、売買契約の当事者にならず、結果を保証しません。売るのは「依頼どおりに実行し、証跡を返すこと」だけです。

Quotes are instant; execution is not. During the launch phase every accepted request is reviewed by a human operator individually before any work starts. We act strictly as agent and never guarantee outcomes — what we sell is faithful execution with evidence returned.
